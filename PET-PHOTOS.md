# Pet photos

Put personal pet photos in [assets/pets](assets/pets/) using these filenames:

- `pet-1.jpg`
- `pet-2.jpg`
- `pet-3.jpg`
- `pets-background.jpg`

You can replace the existing examples by dragging in new photos and keeping the filenames. The site uses `pets-background.jpg` as a subtle background texture. If it is missing, the warm plain background remains.

Use your own photographs only; the project does not use stock animal images.
